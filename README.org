#+TITLE: Gesture Navigation
#+AUTHOR: Rayan Raddatz de Matos

Control my bspwm workspace with hand gestures — because no one likes mouses.
Each hand has one job: right hand focuses windows, left hand moves windows and scrolls.

* Gestures

| Hand  | Gesture                  | Action                                                  |
|-------+--------------------------+---------------------------------------------------------|
| Right | Point a direction        | Focus window that way; falls back to monitor, workspace |
| Left  | Point up / down          | Scroll up / down                                        |
| Left  | Fist + hold displaced    | Move focused window; falls back to monitor, workspace   |

* Setup

#+begin_src bash
uv sync
chmod +x toggle.sh
#+end_src

Then bind =toggle.sh= to a key in your =sxhkdrc=:

#+begin_src
XF86Calculator
    /path/to/mouse-control/toggle.sh
#+end_src

Reload sxhkd:

#+begin_src bash
pkill -USR1 -x sxhkd
#+end_src

Run with =--debug= to see the camera feed:

#+begin_src bash
./toggle.sh --debug
#+end_src

* Dependencies

- [[https://docs.astral.sh/uv/][uv]] — Python environment
- =bspwm= + =bspc= — window manager
- =xdotool= — workspace switching
- =mediapipe= + =opencv-python= — hand tracking
